## 使用过程与对象

| 对象 | 是什么 | 关系 |
|---|---|---|
| **项目** | 会持续开发的对象（个人工作台）| 一个项目有多项任务 |
| **任务** | 某一次有边界的工作（建设 V0.1）| 关联项目；**保存创建时的需求快照与问题快照** |
| **运行记录** | 某次检查的命令、输出、退出码、观察时间 | 多次记录关联同一任务 |

**保存内容副本，不只保存路径** —— 否则改原文件会让旧任务读到新要求。
**快照另存内容哈希** —— 哈希能发现变化，**不判断需求是否合理**。
**失败后修订再检查 ⇒ 增加新记录**，不改旧的，才能看到前后变化。
**记录完整性（`evidence_complete`）与人工验收（`acceptance`）是两件事** ——
前者满足不等于后者完成。

## 五个 CLI 操作

| # | 命令 | 输入 | 输出 | 持久保存要求 |
|---|---|---|---|---|
| 1 | `workbench-init` | `--owner`（真实课程编号）、`--name`、`--runtime-dir` | 工作台身份 JSON | 建立账本与所有者；**不能换所有者覆盖** |
| 2 | `workbench-project-add` | `--project-id`、`--name`、`--path`、`--purpose` | 项目 JSON | 项目编号唯一 |
| 3 | `workbench-task-create` | `--task-id`、`--project-id`、`--request`、`--actor`、`--spec-file`、`--problem-file` | 任务 JSON，含 `requirement_sha256` | **保存 Spec 与问题快照**；任务归属项目 |
| 4 | `workbench-evidence-add` | `--task-id`、`--phase`、`--command-text`、`--output-file`、`--returncode`、`--observed-at` | 记录 JSON | 追加；`--observed-at` **必须带时区** |
| 5 | `workbench-status` | `--require-project`、`--require-task`、`--require-red-green-evidence` | 状态 JSON | **只读**；不改数据、不偷偷初始化 |

全部走**同一个** `workbench.cli` 入口，**保留 `serve-workbench`**。

## 失败行为（**每条都要能运行验证**）

| 情况 | 必须的行为 |
|---|---|
| 未初始化就查询 | 明确失败，提示先 `workbench-init` |
| 项目编号重复 | 拒绝，**不覆盖旧项目** |
| **任务编号重复** | 拒绝，**不覆盖旧任务**；原任务与记录**保持不变** |
| 任务的项目不存在 | 拒绝（任务必须属于已登记项目）|
| Spec 文件或问题文件不可读/为空 | 拒绝，**不产生半条记录** |
| `--observed-at` 无时区 | 拒绝 |
| 查询**不存在的任务** | 非零退出码，指出任务不存在；**已有数据不受影响** |
| 查完整性但缺红—Diff—绿链 | 非零退出码，指出缺什么 |
| 复验后再次失败 | **如实报告失败**，不改写先前记录 |

**错误响应格式**：`{"ok": false, "error": "...", "error_code": "..."}`，
退出码非零，错误码用机器可读的 snake_case。

## 验收项

| 编号 | 前提 | 操作 | 预期响应 | 操作后数据 |
|---|---|---|---|---|
| **WB-01** | 空运行目录 | `workbench-init` 后**结束进程**，新进程查询 | 退出码 0；查回身份与所有者 | 数据在磁盘上，跨进程可读 |
| **WB-02** | 已登记项目 | 创建任务，再查询 | 退出码 0；**需求快照全文一致** | 任务归属该项目；快照是副本 |
| **WB-03** | 已有任务 | **用同一编号提交不同内容** | **被拒绝** | ⭐ **原任务及其记录保持不变** |
| **WB-04** | 已有项目 | 向**不存在的项目**创建任务 | 被拒绝 | 无半条记录 |
| **WB-05** | 已建任务 | **改动外部 Spec 文件**，再查询该任务 | 退出码 0 | ⭐ **快照仍是创建时的内容** |
| **WB-06** | 已建任务 | 追加一条**失败**记录（退出码非零）| 退出码 0（**保存成功**）| ⭐ **红灯记录内部仍是非零退出码** |
| **WB-07** | 已有红—Diff—绿三条 | 查询并带 `--require-red-green-evidence` | `ok=true` ✗ **`acceptance` 仍为 `pending_human_review`** | 数据不变 |
| **WB-08** | 已建任务 | 查询**缺少证据**的情况 | 非零退出码，指出缺什么 | 数据不变 |
| **WB-09** | 已建任务 | 红 ✗ Diff ✗ 绿**时间顺序错乱**时查询 | 非零退出码，指出顺序无效 | 数据不变 |

**观察顺序**：红 → 改动 → 绿灯，`observed_at` 必须**严格递增**。
