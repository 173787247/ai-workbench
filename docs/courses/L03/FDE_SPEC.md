## 来源

**运营原话**（辅导资料 §1）：

> 「我们想知道**还能承诺销售多少**，以及**货在哪里**。」

- **使用目的**：能按商品与位置回答"可承诺量"，并为找不到货时提供定位依据。
- **课程身份**：**课堂角色练习**（图 3-1 / 3-2 的数字为教学推演）。
- **确认人**：⚠️ **待本人填**（规则要求具名）。
- **待确认项**：手册 §2 八行**全部为「待确认」**，其中第 ④⑤⑥⑦ 行的具体取值待查。

## 目标

**导出可定位货物的库存明细。**

## 非目标

- **不发邮件**
- **不自动补货**
- **不修改库存**（成功或失败后业务账都不变）
