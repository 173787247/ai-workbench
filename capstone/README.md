# 每日持仓风控检查

把交易规则里**机械可判**的条目抽成一次**可复算**的检查 ✗
对某一天的持仓快照逐只逐项给出 **通过 / 触发 / 无法判断** 三种结论 ✓

> **这个工具只做算术核对 ✗ 不做交易决策 ✗ 不下单 ✗ 不给买卖建议。**
> 报告末尾永远是 `acceptance: "pending_human_review"` —— **程序不替人签字。**

## 为什么做这个

规则文件自己写着（`docs/AI-TRADING-RULES.md` §0）：

> 「这份文件写的是【规则】（不随时间变）✗ 不是【状态】（每天都在变）。
> **2026-10-12 就犯过这个错**：§0 原写着『总资产 … · 持仓仅 1 只 · 某只占 99.95%』✗
> 而当天下午已经变成『14 只持仓 · 现金 62.6% · 该只已清仓』。
> ⇒ **静态文档里的状态描述一定会过期 ⇒ 一律改成指向工具。**」

规则 1358 行 ✗ 其中**机械可判**的条目分散在各节 ✓
**每天对着它逐个持仓核对 ✗ 容易漏项 ✗ 而且漏了看不出来** ✓

## 快速开始

```bash
# 跑一份快照，人可读报告打到 stdout
python -X utf8 -m capstone capstone/samples/snapshot-2026-10-15.json

# 带「应有持仓清单」→ 启用漏项检测（C0）
python -X utf8 -m capstone snap.json --expected codes.txt

# 落盘（JSON + Markdown）✗ 文件名唯一 ✗ 不覆盖既有报告
python -X utf8 -m capstone snap.json --out runtime/reports/
```

**退出码**：`0` = 全通过或仅 `unknown` ✗ `1` = 有 `triggered`（需人处置）✗ `2` = 快照不可用（受控失败）

**跑测试**：

```bash
python -X utf8 -m unittest discover -s capstone/tests -t .
```

## 快照格式

```jsonc
{
  "as_of": "2026-10-15",              // 快照日期
  "total_assets_pct_base": 1.0,       // 口径基准（恒为 1.0 ✗ 一切用比例表示）
  "cash_weight_pct": 0.226,           // 可用资金占总资产
  "drawdown_pct": 0.031,              // 累计回撤（用于停手线）
  "positions": [
    {
      "code": "AAA",                  // **占位符** ✗ 不含真实标的
      "weight_pct": 0.088,            // 市值占比
      "industry_l1": "制造业",         // 一级行业
      "industry_l2": "半导体",         // 二级行业
      "close": 41.2,                  // 收盘价
      "open_price": 45.0,             // 开仓价
      "atr14": 1.55,                  // ATR(14) ✗ 缺了就判 unknown
      "held_days": 23,                // 持有交易日数
      "unrealized_pnl_pct": -0.084,   // 浮动盈亏比例
      "loss_pct_of_total": 0.0074,    // 单笔亏损占总资产（硬止损用）
      "loss_if_stopped_pct": 0.0074,  // 若止损的亏损占总资产（合计风险用）
      "untradeable_today": false      // 跌停/停牌 → 止损顺延
    }
  ]
}
```

## 检查项

| 代码 | 检查 | 判据 | 规则出处 |
|---|---|---|---|
| **C0** | **漏项检测** | 对照「应有清单」找漏掉的持仓 | 毕设 AC-3 |
| **C1** | **2N 止损** | 收盘价 < 开仓价 − 2 × ATR(14) | §2 |
| **C2** | **硬止损** | 单笔亏损 ≥ 总资产 × 2% | §2 |
| **C3** | **时间止损** | 持有 ≥ 60 个交易日**且未盈利** | §2 |
| **C4** | 单票上限 | 单只市值 ≤ 总资产 × 20% | §1 |
| **C5** | 二级行业上限 | ≤ 20% **且** ≤ 2 只 | §1 |
| **C6** | 一级行业上限 | ≤ 总资产 × 35% | §1 |
| **C7** | 最低现金 | 可用资金 ≥ 总资产 × 5% | §1 |
| **C8** | **停手线** | 黄 2% ✗ 橙 8% ✗ **红 15% → 清仓 + 停手** | §5 |

## 三种结论

| 结论 | 含义 | 必带信息 |
|---|---|---|
| **`pass`** | 未触发 | **算它的输入**（第三方可重算）|
| **`triggered`** | 已触发 | **差值 ✗ 规则出处** |
| **`unknown`** | 缺输入 ✗ 无法判断 | **缺什么 ✗ 为什么** |

> **`unknown` 是一等公民。**
> 缺 ATR 时**不写成通过** ✗ 也不静默跳过 ✓ —— **「不知道」必须出现在报告里。**

## ⭐ 规则唯一的例外：跌停 / 停牌

规则 §2 原文：

> 「触发后**不解释、不等反弹、不改规则** ✗
> **例外只有一条：停牌 / 跌停卖不出 ⇒ 记录并顺延到能卖的第一时间。**」

报告里会单列一节：

```
## ⚠️ 触发但今日不可执行（顺延）
- `C1` DDD：跌停/停牌卖不出（§2 例外）
```

→ **既不是「已执行」✗ 也不是「未触发」✓** ✓

## 覆盖边界（**报告里自动列出**）

**不覆盖**（需要快照里没有的输入 ✗ 如实列出 ✗ **不假装覆盖**）：

- **移动止损**（§2 ✗ 需历史最高价）
- **熔断**（§2 ✗ 系统已有 `kris`）
- **单日买入上限 10%**（§1 ✗ 当日买入数据不在快照里）
- **单一策略上限 30%**（§1 ✗ 策略归属不在快照里）

规则 1358 行 ✗ 本工具只覆盖**机械可判**的九项（含 C0）✓

## 隐私

- **不含真实标的** ✗ 样本用占位代码（`AAA`/`BBB`/…）
- **只有比例与倍数** ✗ 无绝对金额 ✗ 无账户号
- **只读**：不修改任何交易数据 ✗ 不落盘运行数据库
